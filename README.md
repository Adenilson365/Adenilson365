# 🚀 Projetos em destaque

Os projetos abaixo simulam cenários próximos aos encontrados em ambientes reais, abordando arquitetura, automação, segurança, disponibilidade, observabilidade e operação.

### ☸️ Kubernetes HA — On-Premises

Cluster Kubernetes altamente disponível provisionado e configurado utilizando **Ansible**, com arquitetura baseada em **stacked etcd**, múltiplos Control Planes e balanceamento/failover.

**Stack:**

`Kubernetes` `Ansible` `HAProxy` `Keepalived` `Linux` `etcd`

🔗 [Ver projeto](https://github.com/Adenilson365/kubeadm)

---

### 🏗️ Terraform + AWS + EKS

Provisionamento de uma infraestrutura AWS utilizando **Terraform**, organizada em módulos e ambientes distintos.

O projeto inclui EKS, redes privadas, IAM, AWS Organizations, políticas de segurança, Remote State e automação de infraestrutura utilizando **GitHub Actions**.

**Stack:**

`Terraform` `AWS` `EKS` `GitHub Actions` `IAM` `Organizations` `SCP` `Networking`

🔗 [Ver projeto](https://github.com/Adenilson365/tf-labs01-aws-k8s)

---

### 🚀 GitOps Multi-Cluster com Argo CD

Implementação de uma estratégia GitOps utilizando **Argo CD** em ambiente Kubernetes multi-cluster.

O projeto utiliza o padrão **App of Apps**, separação entre aplicações, componentes compartilhados e infraestrutura, além de integração com GitHub Actions.

**Stack:**

`Kubernetes` `Argo CD` `GitOps` `App of Apps` `GitHub Actions` `Helm`

🔗 [Ver projeto](https://github.com/Adenilson365/argocd-lab)

---

### ☁️ Migração On-Premises → AWS

Laboratório simulando a migração de uma aplicação de três camadas para AWS, incluindo aplicação, filesystem e banco de dados.

A arquitetura utiliza conectividade privada e mecanismos de replicação para reduzir o downtime durante o cutover, incluindo estratégia de validação e rollback.

**Stack:**

`AWS` `EC2` `ALB` `Auto Scaling` `RDS` `EFS` `DMS` `DataSync` `VPN` `DNS`

🔗 [Ver projeto](https://github.com/Adenilson365/aws-migration-wordpress)

---

### 📊 Observabilidade em Kubernetes

Implementação de uma stack de observabilidade cobrindo **métricas, logs e traces**, além de dashboards e alertas para aplicações executadas em Kubernetes.

**Stack:**

`Kubernetes` `Prometheus` `Grafana` `Loki` `Tempo` `OpenTelemetry` `Alertmanager`

🔗 [Ver projeto](https://github.com/Adenilson365/devopslabs02-observabilidade)
